# matrix/ —— 黑客帝国风格对照皮肤

这是课程项目的**另一套视觉设计**，用于演示「同一份交互、不同视觉语言」的对照版本。
正式版本仍在仓库根目录的 `src/`，本目录不会替换、也不会被正式页面引用。

## 预览

```bash
node tools/serve.js 8000
# 打开 http://127.0.0.1:8000/matrix/index.html
```

页面需要 HTTP 访问（页面会 `fetch` 仓库根目录 `data/*.json`），直接双击 HTML 不行。

预览截图见 `matrix/img/`：`index.png`、`d1.png`、`d2.png`、`d3.png`；
交互态还有 `d2-choose.png`（A/B/C 判定）、`d3-step10.png`、`d3-final.png`。

## 设计要点

- 深色底 + 荧光绿主色（`--accent: #39ff14`），青色作为「新节点 / 左树」第二强调色。
- 背景是轻量的代码雨（`rain.js`，纯 canvas 装饰），叠加细扫描线；内容层在上、可正常点击。
- 等宽字体栈、方括号标签、`> ` 前缀卡片标题、终端式按钮与高亮选区，强化「终端 / 屏幕」气质。
- 三个难点的语义颜色沿用正式版：路径/后继 = 荧光绿，新节点 = 青色，错误/断链 = 红色，候选项 A/B/C = 绿/紫/红。
- 尊重 `prefers-reduced-motion`：开启减少动态时，代码雨只画一帧静止字符，不循环。

## 与正式版的差别（只有视觉层）

| 项目 | 正式版 `src/` | 本目录 `matrix/` |
| --- | --- | --- |
| 结构 / DOM | 同一套页面结构 | 复制后未改结构 |
| 交互 / 数据 | `src/js/*` + `data/*.json` | **直接复用** `../src/js/*` 与 `data/*.json` |
| 公共样式 | `src/css/style.css` | 先加载它，再由 `matrix.css` 覆盖配色/字体/边框/阴影 |
| 背景 | 浅色纸面 | 代码雨 + 扫描线 |

因此本目录只有 6 个文件：

```
matrix/
  index.html   d1.html   d2.html   d3.html    ← 由 src/ 复制并替换资源路径
  matrix.css                                  ← 主题覆盖层
  rain.js                                     ← 背景代码雨
```

`matrix.css` 只使用选择器覆盖，不改 `src/css/style.css`；`rain.js` 不读写页面数据。
如果决定弃用本皮肤，直接删除 `matrix/` 即可，正式版不受影响。

## 已知取舍

- 代码雨是装饰层，页面滚动时保持 fixed，不参与布局；低性能设备上可删掉 `rain.js` 引用。
- 深色主题下截图/打印建议用浅色正式版；正式提交与演示默认仍用 `src/`。
