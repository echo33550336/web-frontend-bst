# 期末演示脚本（第 16 周）

> 目标：用 4—5 分钟把三个难点串成一条学习路径，说明「规则怎么被维护、顺序为什么重要」。
> 录制前先 `npm run serve`，浏览器打开 <http://localhost:8000/src/index.html>；窗口 1440×900，缩放 100%。
> 建议录 1080p、只录页面 + 画外音（或字幕），不要录到开发工具。

## 0:00—0:30 首页：先给结论

- 停在首页，鼠标依次划过三张卡片（`visited` 样式会亮起）。
- 画外音：「二叉搜索树只有一条局部规则——左边全小、右边全大。这条规则保证中序递增。三个难点是同一个问题的三个侧面：插入怎么找位置、删除怎么不破坏规则、插入顺序怎么决定树好不好用。」
- 若 localStorage 里已有进度，指一下「学习进度：x / 3」提示。

## 0:30—1:40 难点 1：插入路径（参数探索型）

1. 停留在默认树（`50 / 30 70 / 20 40 60 80`），指右侧「允许区间 (50, 70)」和「候选位置 8 个」。
2. 把「插入值」滑块从 65 拖到 20，再拖到 90：路径与区间实时重算，候选数从 8 → 4 → 2 → 1。
3. 点「开始插入」：播放比较路径，节点按 `50 → 70 → 60` 高亮，落点区间收窄到 `(60, 70)`，最后挂到 60 的右孩子。
4. 点「随机重生成」换一棵树，重复一次，强调「路径唯一 ⇒ 位置唯一」。
- 收尾句：「插入不改变规则，只是找到规则允许的唯一空位。」

## 1:40—3:10 难点 2：删除双孩子（步进推演 + 判定）

1. 情形选「双孩子（删除 50）」，点「播放」走前四步：进右子树 → 一路向左 → 找到后继 60 → 准备摘挂。
2. 到第 5 步「A/B/C 判定」时暂停，念题干，先故意点 **C（直接拿孩子顶替）**：页面演示断链、丢节点，提示可以重试。
3. 点「重新选择」，改选 **A（中序后继）**：继续走摘挂动画，最后进入校验区，看到中序仍递增、BST 规则通过。
4. 用「上一步」退回判定前，再「下一步」走一遍，说明「每一步都是快照，前进后退结果一致」。
- 收尾句：「删除双孩子不是随便找个孩子顶替，而是用中序后继把位置补上，规则才继续成立。」

## 3:10—4:20 难点 3：插入顺序与退化（对照比较）

1. 默认「规模 20、有序程度 100%」：左右两棵树完全一样，都是升序链。
2. 把「有序程度」拖到 0%：左树立刻变矮变宽，右边仍是链；三张读数卡左/右对比拉开。
3. 点「播放」看两棵树同步长高；暂停在中间，指折线图只画到当前步。
4. 把折线读数从「树高」切到「平均查找步数」，说明纵轴换了、当前步不变；再切到「最坏查找步数」。
5. 点「重排」：同一批数、同一个 n，只换左树插入顺序，折线重画；强调「数值集合没变，变的只有顺序」。
6. 拖到 n=60（紧凑模式，节点数字隐去），说明规模变大时看形状和读数。
- 收尾句：「规则一直被满足，形状却完全不同——这就是退化。顺序不改变正确性，但决定代价。」

## 4:20—4:50 收尾

- 回首页，指学习进度：「三页就是一条路径：路径决定位置 → 删除不动规则 → 顺序决定形状。」
- 补一句工程说明：「讲解文字、步骤、参数、A/B/C 选项都在 `data/*.json`，代码只负责渲染；三页共用一套树模块与测试。」

## 备用方案与注意事项

- **网络/字体加载慢**：页面无外部依赖，刷新一次即可；不要录首次白屏。
- **动画节奏**：录制时把速度调到 3—4 档，避免等待；单步演示优先于点播放。
- **A/B/C 选错演示**：选 C 后出现断链快照，点「重新选择」即可恢复，不要刷新页面。
- **口误/重录**：每页可单独重录，后期按页面拼接；保持首页 → d1 → d2 → d3 的顺序。
- **不要展示**：开发工具、本地文件路径、`localhost` 地址栏以外的隐私信息。
