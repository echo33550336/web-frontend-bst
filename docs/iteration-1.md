## 4. 问题与改进

- 遇到的问题：①沙箱里 npm 缓存目录不可写；②骨架页没有 `tree.js`，页面测试却能过（因为当时只测文字）；③d2 判定后果的教学口径；④d3 大 n 时节点数字挤在一起。
- 原因：①环境限制；②测试覆盖的是「能渲染」而不是「图表正确」；③「失序」直觉与标准 BST 直接顶替的真实结果不一致；④固定坐标盒 + 60 个节点的物理限制。
- 下一轮怎么改（具体动作，不写"继续优化"）：①安装脚本固定 `--cache .npm-cache`；②所有页面冒烟测试都断言 SVG 里至少有一个节点与一条边，并在 smoke 中检查脚本顺序；③C 选项反馈改为断链 + 丢节点清单（已改）；④n≥23 自动 compact 隐藏数字并显示 JSON 提示（已改）。
